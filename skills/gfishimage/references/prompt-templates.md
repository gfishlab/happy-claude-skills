# 手绘信息图提示词模板库

## 基础模板

```
A hand-drawn infographic illustration about [主题].
Style: sketchy doodle, rough strokes, crayon texture, marker coloring.
Layout: landscape 16:9, clean composition, generous whitespace, organized visual flow.
Content: [具体元素].
Colors: [不超过4种柔和色], white/cream background.
Text: [中文关键词，每个不超过6字].
Constraints: No 3D rendering, no photorealism, no dense text.
Playful and minimal.
```

## 流程图模板

```
A hand-drawn flowchart about [主题] in doodle style.
Style: rough sketch lines, crayon coloring, playful marker doodle.
Layout: landscape 16:9, [N] rounded boxes connected by curved arrows, flowing [top-to-bottom / left-to-right].
Content: Each box represents a step. Arrows show the flow.
Colors: soft blue boxes, amber arrows, mint highlights, charcoal text, white background.
Text in boxes: [步骤1], [步骤2], [步骤3], [步骤4]...
Constraints: No 3D, no photorealism. Each text label is 1-6 Chinese characters max.
```

## 对比图模板

```
A hand-drawn comparison infographic about [主题A] vs [主题B].
Style: doodle sketch, crayon texture, marker coloring.
Layout: landscape 16:9, split into left and right halves, VS badge in center.
Left side: [主题A 关键特征].
Right side: [主题B 关键特征].
Colors: left side [色A], right side [色B], white background.
Text: short Chinese labels only (1-6 chars each).
Constraints: No 3D, no photorealism.
```

## 列表/要点图模板

```
A hand-drawn list infographic about [主题].
Style: sketchy doodle, crayon texture, marker coloring.
Layout: landscape 16:9, [N] items arranged vertically, each with a small icon/sketch and short label.
Content: [要点1], [要点2], [要点3]...
Colors: [主色] for icons, charcoal for text, white background.
Text: Chinese labels, 1-6 characters each.
Constraints: No 3D, no photorealism, generous whitespace between items.
```

## 架构图模板

```
A hand-drawn architecture diagram about [主题].
Style: doodle sketch, crayon texture, rough strokes.
Layout: landscape 16:9, layered boxes showing [N] tiers/layers.
Content: Top layer: [层1]. Middle: [层2]. Bottom: [层3]. Arrows connecting layers.
Colors: each layer a different soft pastel color, white background.
Text: Chinese labels in each box, 1-6 characters.
Constraints: No 3D, no photorealism. Clean and minimal.
```

## 时间线模板

```
A hand-drawn timeline infographic about [主题].
Style: doodle sketch, crayon texture, marker coloring.
Layout: landscape 16:9, horizontal timeline with [N] milestone markers.
Content: milestones from left to right, each with a small doodle icon.
Colors: soft gradient of [色1] to [色2], white background.
Text: Chinese milestone labels, 1-6 characters each.
Constraints: No 3D, no photorealism.
```
